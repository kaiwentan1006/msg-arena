What's a "self-hosted" server?

It means the chat runs on YOUR computer, not a company's server. Your messages never leave your machine. You're the cloud.

!

Do my friends need to download anything?

Only if they want to. A link in any modern browser works with nothing installed, phones included. If they would rather have a real app, there is a desktop app for Windows and Linux and an Android app on Google Play. Same server either way.

🔒

Is it secure?

HTTPS encryption, bcrypt passwords, JWT auth, rate limiting, CSP headers, and more. Check the source code yourself.

💻

What do I need?

Windows, Mac, or Linux. Node.js (free, 2-click install). About 50 MB disk space. That's everything. Or use Docker: docker compose up -d and you're done.

All the features

MSG Arena isn't a toy. It's a full-featured chat platform.

📥

Discord Import

Import your entire Discord server's history directly from MSG Arena, channels, threads, forums, reactions, pins, attachments, and avatars. Paste your token, pick a server, done.

🛶

Ferry: Two-Way Discord Bridge

Messages pass both ways between a MSG Arena channel and a Discord channel, under each person's real name. Friends who stay on Discord can still talk to the ones who left.

🎮

Rich Presence

See what everyone is playing and listening to. Steam for games, Last.fm or Spotify for music. Optional, and never saved to the database.

🎵

Music & Video Streaming

Spotify, YouTube, and SoundCloud Listen Together with synced playback and seek bar. Share audio files or screen-share a movie, everyone hears and sees it together in real time.

💬

Rich Chat

Real-time messaging, image uploads, typing indicators, message editing, replies, emoji reactions, @mentions, and editable channel names with collapsible sub-channels.

🎙️

Voice Chat

Peer-to-peer audio. Per-user volume sliders. Mute, deafen, noise suppression. Talking indicators.

🖥️

Screen Sharing

Multi-stream support. Tiled grid layout. Resizable viewer. Share screens simultaneously.

🔒

Encrypted Direct Messages

End-to-end encrypted DMs using ECDH + AES-256-GCM. Keys sync across devices via password wrapping. Not even the server host can read them.

🎨

26 Themes, Plus Your Own

Matrix, Tron, HALO, Cyberpunk, Dark Souls, Elden Ring, Minecraft, Win95 and more, plus a colour picker and a plugin system for your own.

🎞️

GIF Search & /gif Command

Search and send GIFs inline, powered by Tenor. Free API key, one-click admin setup. Star the ones you reuse.

📁

File Sharing

PDFs, docs, audio, video and archives, with inline players. 25 MB per file by default, raise it as far as your disk allows.

🔗

Link Previews

Automatic OpenGraph previews for shared URLs with title, description, and thumbnail.

⚡

Slash Commands

/shrug, /tableflip, /roll, /flip, /me, /tts, with autocomplete and descriptions.

🔍

Message Search

Ctrl+F to search any channel. Results with highlighted matches and jump-to-message.

📌

Pinned Messages

Admins can pin important messages. Dedicated panel to browse all pins in a channel.

🛡️

Moderation Tools

Roles with per-channel permissions. Kick, mute, ban, IP bans, slow mode, automod link filtering, and an audit log.

🌐

Multi-Server

Add friends' MSG Arena servers to your sidebar. Live online/offline status indicators.

🔔

Notification Sounds

5 distinct tones. Per-channel volume. Enable/disable per channel. Unread badges persist.

🎮

Games & Activities

Shippy Container, Flight, Learn to Fly 3, Bubble Tanks 3, Tanks, Super Smash Flash 2, and .io games. Server-wide leaderboards. Flash games via Ruffle emulator.

🧵

Threads

Branch a conversation off any message. One button lists every thread in the channel, with search.

🔑

Single Sign-On

Sign in with your own identity provider: Authentik, Keycloak, Authelia, Auth0, anything speaking OpenID Connect.

🤖

Bots & Webhooks

A REST API for bots: send messages, play soundboard sounds, register slash commands, join voice, get signed callbacks.

⬆️

One-Click Updates & Backups

Update from inside the app. MSG Arena backs itself up first, then restarts. Backups also run on a schedule, with restore.

📲

Push Notifications

Real-time notifications on mobile and desktop, with UnifiedPush if you would rather leave Google out.

🎭

Stickers, Personas & Polls

Your own sticker packs and emoji, alternate characters with ::Name, polls, and a soundboard.

🚪

Guests & Invites

Temporary guest logins, invite links, and per-channel join codes that rotate on their own.

🌐

8 Languages

English, French, German, Spanish, Polish, Russian, Chinese and Brazilian Portuguese, community translated.

☁️

Connect Without Port Forwarding

Built-in Cloudflare and LocalTunnel support, plus guides for Tailscale and reverse proxies.
